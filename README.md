## Опыт с данными

### BCH Labs — аналитик данных и руководитель проекта
03.2025 — 09.2026 · удалённо · торговый бот на блокчейне Solana · команда до 5 человек: DevOps, ML-инженер, Rust-разработчики

Данные — поток on-chain событий и история за месяцы торгов в ClickHouse (кластер с шардированием) и PostgreSQL.

**Хранилище и витрины.** Команде нужна была единая история, на которой воспроизводимо считаются признаки и бэктесты.
- Вела структуру таблиц, репарсинг сырых транзакций в события и дозагрузку пропущенных периодов по эпохам (ETL)
- Писала миграции и DDL: таблицы признаков, разметки кошельков, рыночных метрик; ReplacingMergeTree и Distributed-таблицы
- Собрала витрину рыночных метрик по эпохам
- Нашла методологическую ошибку в метрике, которая показывала 103,5%, и заменила источник данных

**Дашборды.** Результаты торговли и состояние рынка нужно было видеть без ручных выгрузок.
- Три дашборда в Grafana, 35 панелей: анализ торговой сессии (15), paper-trading (10), здоровье рынка (10)
- Все метрики считаются SQL-запросами к базе, конфигурация через API Grafana
- Починила кросс-табличные джойны на распределённых таблицах: 28 панелей вернулись из состояния No data
- Итог: PnL, проскальзывание и рыночные метрики доступны команде в реальном времени

**Классификатор кошельков.** Задача — выделить из потока событий кошельки, чьи сделки имеет смысл копировать.
- SQL-пайплайн из 12 шагов: PnL по токенам, детект ботов, агрегация статистики, классификация, фильтры, граф переводов
- Признаки на реализованном PnL: win rate, profit factor, композитный skill score
- Итог: кросс-проверка разметки через внешний API — 0,5% ложных срабатываний

**Проверка гипотез.** Команда хотела понять, что на самом деле повышает доходность.
- A/B/C/D-тест параметров исполнения и форвард-тест на 9 торговых сессиях (~780 сделок)
- Итог: четыре гипотезы роста доходности закрыты количественно — команда не потратила месяцы на ложные направления

**Управление проектом.** Параллельно вела команду: недельные спринты с целями по результату, бюджет через трекинг часов, найм трёх ролей полным циклом.
